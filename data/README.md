# Data for replication

This directory contains the data required to replicate the computational experiments.

The Flat Instances folder contains the static instances generated by Ghamlouche et al. (2003), “Cycle-Based Neighbourhoods for Fixed-Charge Capacitated Multicommodity Network Design”.

The Instances with Travel Time Uncertainty folder contains the corresponding timed instances with travel-time uncertainty, which were generated from the static instances and used in the computational experiments conducted in this study.

Both folders include an illustrative example explaining the instance format.
