## Restuls

This folder contains raw, instance-level algorithm performance results for the two methods reported on in paper

Ro_results: reports instance-level results for the robust optimization method.

Ro_results: reports instance-level results for the robust satisficing method.

Moreover, the `FTNSP_Results` file reports instance-level results obtained using the DO method for the FTNSP instances introduced by Hewitt and Lehuédé (2025) in “The Freight Transportation Network Scheduling Problem: An Integer Programming-Based Column Generation Algorithm.”
